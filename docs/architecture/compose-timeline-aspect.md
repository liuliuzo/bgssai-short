# 合成时间轴与画幅

对应 [REQ-SHORT-COMPOSE-TIMELINE-20261111](../feature/film-compose-export.md)。无页面/REST/数据库字段变更，不改HTML原型；本次是已有时间轴与保存画幅的后台落实。

Worker 显式将有效 work.aspect_ratio 放入 COMPOSE 内部 params.aspect_ratio。设置保存已同步该字段；默认9:16，接受9:16、16:9、1:1、3:4。clip_list 与 clip_duration_sec_list 必须等长，每个计划时长为正整数；配音列表存在时也须保持同一镜头索引，不跳过无声镜。

Provider 对每段已生成视频运行有超时和输出上限的本地 ffprobe，仅用视频流精确duration检查覆盖。不能用容器音轨长度掩盖视频不足，不能用 MediaMetadata 的向上取整计量秒数代替检查。无法确认时长、无视频流、短片或无效参数均明确失败；允许小于1毫秒的浮点表示误差，不补冻结画面。

每片先 setpts 归零、trim 到计划秒数，再等比缩放/留黑边，统一30fps、SAR=1、yuv420p、H.264、90000轨道timebase。每片只编码视频，concat只拼规格一致的规范化视频。源非方形像素先还原显示比例；不拉伸、不开裁切。

如果有配音，以配音逐镜替换原音；否则保留有音轨的原片音频。空镜头音轨用等长静音占位，每段归零、apad/atrim，统一44100Hz双声道PCM。完整PCM轨拼接后只编码一次AAC，不拼接各镜AAC延迟。字幕/BGM叠加继续使用既有流程；最终精确媒体元数据仍由已有 MediaMetadata.verify 校验，本次不修改它。

ffmpeg/ffprobe进程等待受超时控制，日志写入本任务临时目录，失败仅保留有限诊断片段。每片规范化编码使用2线程，串行处理片段，避免并发放大内存。临时文件仅清理本次创建目录。

验证：真实ffmpeg动态fixture，覆盖原片大于计划、非零时间戳、不同fps/时间基、尾镜无原音、原音/配音与BGM、9:16/16:9/1:1/3:4输出和留边、精确短片拒绝。边界前后及尾帧检查确保不是仅总时长正确而丢镜头。测试不访问真实作品、模型或部署服务。
