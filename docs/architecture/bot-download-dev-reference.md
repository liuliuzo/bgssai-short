# 下载页视觉校准设计

需求版本：2026-11-09，见 `../feature/bot-download-dev-reference.md`。

局部 CSS 仅调整下载页标题、内容内距与表格卡片，不修改全局主题。原生 iOS 限定 BotDownloadsView。保留已有渐变、最大宽度与数据加载逻辑，表格字体继承衬线主题。窄屏卡片保持 24px 内距并由既有横向容器承载宽表格；不回退单字竖排。

HTML 原型只演示布局与未发布样式，不定义新接口或发布状态。真实页面保留原有空态、加载态、错误态、平台信息与下载链接。API / SQL / 鉴权 / 返回路由均不涉及。

验证：构建实际前端，并在 1280px 和 390px 视口检查标题、卡片、留白、滚动、真实响应渲染和链接。原生构建需 macOS/Xcode，本机未具备时须如实记录。PR 状态、构建与部署分别报告。
