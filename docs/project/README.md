# docs/project（项目进度）

本目录承载**项目进度**类文档：里程碑与排期、迭代计划与收敛记录、待办与风险清单、发布记录等。

## 与其它目录的边界

| 内容 | 归属 |
| --- | --- |
| 功能需求澄清 + 详细设计（WHAT / HOW） | `docs/feature` |
| 架构设计 / ADR / 数据模型 / 状态机 | `docs/architecture` |
| 接口契约 | `docs/api` |
| 原型与页面跳转 | `docs/demo-static` |
| 安全设计 / 威胁建模 | `docs/security` |
| 检查（CR / 验收 / 巡检）记录 | `docs/review` |
| **进度 / 排期 / 里程碑 / 发布记录** | **本目录** |

进度文档只记录「做到哪一步、什么时候做、谁在做、卡在哪」，**不承载需求与设计正文**——需求与设计的单一
事实来源仍是 `docs/feature` 与 `docs/architecture`，本目录只做引用，避免出现第二份需求副本。

## 约定

- 每份进度文档一个主题，命名用小写连字符，如 `milestones.md`、`iteration-2026-08.md`、`release-log.md`。
- 进度条目须可追溯：引用对应功能文档（`../feature/<feature>.md`）与 PR / 提交，不写无出处的结论。
- 状态词统一用：`未开始` / `进行中` / `已完成` / `已阻塞` / `已取消`，不自造同义词。
- 本产品当前进度见 `milestones.md`；后续按主题增补迭代计划与发布记录。
