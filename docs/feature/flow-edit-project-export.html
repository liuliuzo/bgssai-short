一、两个出口的前置条件对照：合成是为了发，导出是为了改

这张图是本功能唯一要守住的判断：把导出的前置照抄合成，功能会在「已经不需要改」的时刻才可用， 等于没做。两个出口服务的是两件事，前置就必须不同。

二、导出管线：一次导出一种格式，缺片留空不补占位

三、缺片镜头的处理：留空档，不插黑场

与成片合成「缺片直接失败并点名缺哪几镜」是同一条口径的两面：合成阶段假成片会骗人， 导出阶段假素材同样会骗人。两处都不做兜底占位。
