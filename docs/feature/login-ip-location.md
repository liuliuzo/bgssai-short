# 登录日志 IP 归属地

用户端和管理端登录日志在“登录IP”旁展示“IP归属地（参考）”，内容为离线库可识别的国家/地区/城市。IP 归属地不代表登录者或设备的精确位置，代理/VPN 和数据库更新也会影响结果。

- 用户端只看本人记录，管理员保留全库记录权限；排序、物理分页与总数不变。
- 历史 ip_address 不改写；查询时仍解析只读 ip_location。登录明细另把当时能解析出的国家、省区、城市和运营商记在登录行上，见 [登录明细](login-log-detail.md)。
- 本地回环显示“本地”，私网/链路本地显示“内网”，保留/文档/共享地址等显示“非公网地址”。
- 当前复用 Note 的 IPv4 离线库；公网 IPv6 显示“未知（IPv6 暂未覆盖）”，无效、空值和未命中显示“未知”。
- 不发送 IP 给在线定位接口，不请求浏览器定位，不展示街道、经纬度或推测的精确地址。
- 新写入审计只接受同机回环反代追加的最右端 X-Forwarded-For 地址；直连不信任转发头。历史记录保留原始采集可信度限制。
