二、派生链：人只在前两层作业，提示词永远是派生物

三、一集的实际作业顺序

这条链路的取舍：文字稿之所以可直接编辑、而提示词之所以只读，是因为两者的作者不同—— 文字稿是创作者的构想，提示词是系统按一致性规则拼装的执行指令。让人改构想、让系统管执行， 既保住了跨镜头一致性，又把「想清楚」这件事放回到了它该在的位置：生成之前，而不是生成之后。
