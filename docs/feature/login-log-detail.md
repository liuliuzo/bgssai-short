# 登录日志明细

用户端和管理端的登录记录除 IP、归属地和时间外，展示登录当时能够确定的结果、方式、账号、设备、请求和会话。采集不到的项保持空白，页面上显示未知。

- 结果：成功或失败，以及固定原因（登录成功、账号或密码不正确、无管理端权限、验证码错误或已过期、第三方登录未完成、账号不可用）。不记录口令、验证码、JWT、Cookie 或第三方授权码。
- 方式：密码、邮箱验证码、手机验证码、微信、支付宝、抖音、百度、BGSSAI 账号。用户端与管理端密码登录都会记。
- 账号：用户名原文；邮箱、手机号脱敏。第三方登录只写渠道名。
- 客户端：用户端网页、管理端。请求若已经带 `X-Bgssai-Client: app`，记为应用。
- 设备：从 User-Agent 解析浏览器、系统和桌面 / 手机 / 平板。认不出则留空。
- 网络：沿用现有可信 IP。离线库能给出的国家、省区、城市、运营商在登录时记下。没有的段留空，不编造。`ip_location` 仍是查询时的参考归属地。
- 请求：协议、应用自己终止 TLS 时的版本、来源主机、入口路径、traceId、Accept-Language。时区和屏幕只在请求已经带上时记录。来源和路径去掉查询串。
- 会话：成功登录记下会话标识、签发时间和按 JWT 有效期算出的过期时间。之后鉴权通过会更新最近活跃。主动退出记下退出时间。失败记录没有会话。
- 对照：只和该用户更早、且已经记下设备或城市的成功登录比较「新设备 / 曾用设备」「新城市 / 曾出现城市」。没有可对照历史时留空，不打分。

用户端只看本人。管理端看全库。点一行打开详情。退出登录会通知服务端结束当前会话。

旧记录没有这些列时，结果可以从原动作推出，设备可以从已保存的 User-Agent 推出，地区可以按当前离线库补全并标明不是当时快照。其余仍为未知。
