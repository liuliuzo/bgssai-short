# 失败回调与视频恢复的状态一致性

已绑定镜头视频继续可播放，但旧失败/取消回调不得降级正在恢复或后续任务的镜头状态。只有本次任务状态更新成功，且原任务仍是同一重试版本的 FAILED/CANCELED，才允许尝试恢复已绑定素材对应的就绪状态；成功任务、重新排队或运行的任务不受旧回调影响。

最终落库同时核验任务归属、重试版本和终态、镜头更新时间/镜头版本/提示词版本/当前素材，以及不存在同镜同类型后续或活动任务。镜头状态仍为对应 GENERATING 才能回退，锁定/已完成/并发修改均保留，不解绑或替换素材，不提交新的生成请求，不改变费用。

对外任务响应仅在 FAILED 时返回 fail_reason_code 与 fail_reason。成功、排队、运行、暂停和取消任务不展示历史失败字段；历史数据库记录不因此被批量改写。Web 与 MCP 复用同一安全任务视图。

本次保留已合并的列表视频播放与参考图预览，并由官方脚本重新生成原型/代码锁；源码、原型与锁一致后才允许发布。无新表、字段或数据库迁移。
