# 定妆知识库

## 一、背景与目标

定妆不能只靠模型现画。创作者可以上传自己的角色、场景、道具图片或一段参考视频，直接锁定为定妆照，也可以把这些素材放进知识库，生成候选时作为参考。

## 二、需求澄清

- 用户故事：作为创作者，我上传一张自己的图片，锁定后全剧按这张图保持形象。
- 用户故事：作为创作者，我把多张定妆素材放进知识库，也可以放一段参考视频。生成该角色或场景的候选时，系统按名称和说明选出最接近的一张，交给图像模型作主体参考。视频用它的一帧画面。
- 业务规则：
  1. 图片接受 JPG、PNG、WebP，视频接受 MP4，都最大 6MB。
  2. 角色定妆照分四面：正脸、前面、背面、侧面。正脸上传后立即锁定，作为全剧生成时交给模型的那一张。另外三面保存在这张角色卡和知识库里，生成时如果名称对得上，优先用正脸。场景和道具仍是一张参考图。
  3. 知识库可以有多个。页面左侧用列表选出当前库，不用下拉框。库里按造型分成一组，正脸、前面、背面、侧面各点空位上传，同一面可以再传一张。新建库只填名称，默认在生成时参考。关掉「生成时参考」后，生成不再使用里面的图。
  4. 点「定妆」或「生成参考图」时，先用这张卡已经放进知识库的图。角色优先用正脸，没有正脸再用前面、背面、侧面。这张卡没有图时，用开发环境已有的 Elasticsearch 按名称和说明检索整库，召回最接近的一张。命中视频时，用该视频的一帧画面。对上至少 3 个字，或名称被描述包含，才把那张图交给模型。检索不可用时仍按名称在库内比对。都对不上就只按文字生成。
  5. 上传不扣模型费用。生成候选仍按原价确认。

## 三、验收标准

1. 角色卡上传自己的图片后，候选里出现这张图，锁定后状态为已定妆。
2. 同一张图进入「我的定妆」或创作者指定的已挂载知识库。
3. 知识库页左侧列出全部知识库。选中后按造型看四面，点空位上传图片或 MP4，可以移除。可以新建库。
4. 外观描述能对上素材名称或说明时，定妆生成把检索到的图作为主体参考；对不上则不附带。

## 四、接口

- `GET /bgssai/user/look-libraries/list`
- `POST /bgssai/user/look-libraries/save`
- `POST /bgssai/user/look-materials/upload`
- `POST /bgssai/user/look-materials/delete`
- `POST /bgssai/user/characters/portrait-upload`
- `POST /bgssai/user/scene-cards/portrait-upload`

鉴权需 `Jwttoken`，只操作当前用户自己的库和卡。
