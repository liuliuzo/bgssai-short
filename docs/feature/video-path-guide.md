# 出视频步骤（video-path-guide）

本功能不新增制作能力、接口、字段、枚举或库表。作品工作台顶部以单一八步可交互环节条作为主导航，取消下方重复平铺页签栏。

## 主流程与状态标识

当前剧集主流程固定为八步：

`1 大纲 → 2 剧本 → 3 定稿 → 4 定妆 → 5 拆镜 → 6 首帧 → 7 视频 → 8 成片`

1. 顶部进度头显式展示当前进度：`当前环节：第 N/8 步 · <环节名>`（全部完成时显示 `全流程已完成（8/8）`）以及 `已完成 X/8 步`。
2. 8 个步骤按钮依次展示序号 `1`–`8`、环节名称与状态标签（`已完成` / `当前环节` / `生成中` / `未开始`）。
3. 环节判定口径：
   - 大纲：无大纲时为 `1 大纲`；正在生成大纲时停在 `1 大纲（生成中）`。
   - 剧本：已有大纲、本集无剧本时为 `2 剧本`；正在生成剧本时停在 `2 剧本（生成中）`。
   - 定稿：剧本处于草稿态时为 `3 定稿`；提供单一「定稿」入口，节奏分低于 60 时弹窗确认后定稿，定稿完成后置为「已定稿」。
   - 定妆：存在未锁定参考图的角色、场景或道具时为 `4 定妆`，一次处理列表首项；已有图则锁定，无图则确认费用后出 2 张并锁定首张；生成中停在 `4 定妆（生成中）`。
   - 拆镜：无镜头或镜头缺少画面描述时为 `5 拆镜`。
   - 首帧：存在未生成首帧的镜头时为 `6 首帧`；生成中停在 `6 首帧（生成中）`。
   - 视频：镜头均有首帧但存在未生成视频的镜头时为 `7 视频`；生成中停在 `7 视频（生成中）`。
   - 成片：镜头视频齐全待合成时为 `8 成片`；`compose_status=READY` 时全部 8 步均为 `已完成`。

## 交互与自动定位

1. 点击八步中任一环节，切换至对应核心工作区（`script` / `characters` / `storyboard` / `compose`）并附带 `?stage=<key>` 定位子区块；当前查看环节与当前待办环节不一致时，节点标签显示 `查看中`，动作栏提供 `返回当前环节：<环节名>` 按钮。
2. 从 `/works/:workId`（无 `:tab`）进入作品或切换 `当前剧集` 时，自动定位并打开该剧集当前待办环节所在工作区；通过步骤条完成步骤推进后，工作区同步切至新的当前环节。
3. 剧本工作区：大纲已生成且当前焦点不在 `大纲` 时，默认将 `全集大纲` 收折为单行摘要栏（提供 `导入原著` 与 `展开编辑大纲` 按钮），置顶显示当前剧集剧本与定稿卡片；不保留旧版 `第 1 步：剧本与定稿` 标题。
4. 分镜工作区：顶部仅保留「上下列表 | 按场次排」切换、进度计数、一键确认提交的「生成首帧」「生成视频」与「更多操作」（全选本集、勾选待出视频、同场画面自动衔接、重写画面描述、重新拆镜）；缺描述镜头自动补齐并支持失焦与提交前自动保存；全部视频就绪且未勾选时顶部收起为成片/配音入口与「批量重做」。
5. 页头右上角提供 `辅助工具` 下拉菜单收纳非必经扩展页（`原著`、`配音`、`预览`、`剧情`、`质量`、`连贯性`、`任务`、`剪辑`），原有 `/works/:workId/:tab` 路由不变；处于辅助工具视图时展示当前工具名称与 `返回当前环节` 入口。
6. 顶栏作品标题旁标明 `全剧：<作品状态>`；非成片页剧集标签展示 `本集环节：N/8 <环节名>` 或 `本集进度：8/8 已完成`，成片页保持成片预检状态口径。

## 不改的规则

- 不新增接口、字段、枚举、表。
- 定妆必须锁定后方可出图与出视频。
- 视频必须先有首帧。
- 费用走既有预估确认流程；定妆候选数仅允许 `2 / 4 / 8`。
- 成片合成、配音、审核、发布仍在既有子页内完成。
