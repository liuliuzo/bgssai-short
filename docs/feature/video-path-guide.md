# 出视频步骤（video-path-guide）

作品页原来把原著、剧本、角色、分镜、配音、剧情、质量、预览、连贯性、任务、成片、剪辑并列。生成视频的前置条件（剧本定稿、定妆锁定、首帧）散落在不同页签，没做完就点「生成视频」会被拒绝。创作者不知道下一步该点哪里。

本功能不新增制作能力，也不新增接口。它在作品页顶部按真实门槛排成一条步骤，每一步只给一个主按钮。

## 步骤

当前剧集从左到右只有这一条：

大纲 → 剧本 → 定稿 → 定妆 → 拆镜 → 首帧 → 视频 → 成片

1. 没有大纲：生成大纲。正在生成时不再重复提交。
2. 大纲已有、这一集还没有剧本：生成这一集剧本。
3. 剧本已是草稿：定稿。节奏分不到 60 时，旁边给出强制定稿。定稿才会抽出角色、场景、道具。
4. 还有未锁定的定妆卡：一次只处理一张。已有图就锁定，不花钱；没有图就出 2 张并锁定第一张，先确认费用。没锁定的卡，出图和出视频都会失败。
5. 还没有镜头：从剧本拆镜，并写好人话分镜。这一步不花钱。
6. 镜头没有画面描述：先写人话分镜。
7. 还没有首帧：确认费用后出首帧。没有首帧不能生成视频。
8. 已有首帧、还没有视频：确认费用后，只提交这些镜头。
9. 镜头视频已经齐：去成片页合成。配音不挡这条入口。成片已就绪则只查看。

正在生成的大纲、剧本、定妆、首帧、视频会停在当前步，按钮不再重复提交，页面自己刷新。

其他页签仍在，顺序改成先放剧本、角色场景、分镜、成片。原著、配音、预览、剧情、质量、连贯性、任务、剪辑留在后面，不作为出第一条视频的必经步骤。

首页「继续」在剧本未定时写「去写剧本」，分镜未完成时写「去生成视频」。

## 不改的规则

- 不新增接口、字段、枚举、表。
- 定妆仍必须锁定后才能出图、出视频。
- 视频仍必须先有首帧。
- 费用仍走原来的预估确认。定妆一次 2 张，候选数仍只允许 2 / 4 / 8。
- 成片合成、配音、审核、发布仍在原来的页面里做，步骤条只负责打开成片页。
