# 额度套餐与 token 显示（2026-10-17）

对应需求：`REQ-SHORT-COMMON-018`、`REQ-SHORT-COMMON-019`。

## 功能

1. 套餐页展示当前套餐、剩余额度、到期时间，以及开通/续费/加量入口。
2. 额度以支付成功回调入账；`payment_order.order_no` 唯一，重复回调只入账一次。
3. 额度按真实 token 计量；界面 K/M/B 紧凑写法（如 418.9M），悬停精确整数；接口字段 `*_tokens` 为精确整数，`*_cent` 兼容别名同值。售价仍为人民币分。

## 说明

本仓钱包整数即 token。若历史数据曾按「点」解释，换算规则未单独确认的场景在用例记阻塞。
