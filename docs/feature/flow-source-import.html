一、三种源进来后各自跳过哪几步

这张图要守住的是最右边那一格：有原著不是节奏合格的理由。 小说改编最典型的翻车方式就是照搬小说节奏——铺垫长、对白书面、一集讲不完一个爽点， 而这正是体检拦的东西。给改编稿开体检的口子，等于把这个功能变成批量生产「小说腔短剧」的机器。
