站内在线客服 · 会话 + 工单流程

用户 / 访客

打开悬浮入口
→
气泡区 + 底部输入（无表单）
→
首条留言 create → PENDING
→
send / detail 看历史气泡
→
提工单 → ticket OPEN（可继续聊）

管理端

sessions/list（含 ticket_status）
→
detail + ticket
→
reply → OPEN
→
update_status 工单
→
close 会话 → CLOSED

访客端无必填联系方式 / 主题表单。聊内提工单为正式化升级，不替代对话。会话状态：OPEN / PENDING / CLOSED。工单状态：OPEN / IN_PROGRESS / RESOLVED / CLOSED。
