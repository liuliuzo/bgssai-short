# 用户登录页整理（2026-09-26）

> 原型：`docs/demo-static/web/user/login.html`
> 详设：`docs/architecture/login-page-cleanup-20260926.md`
> 口径：骨架 [全局开发规范](https://github.com/liuliuzo/bgssai-skeleton/blob/develop/docs/BGSSAI-Standards.md) §14 登录页统一口径、§15 法务同意行与页脚

## 背景

登录页左侧是营销栏（标语 + 卖点 + 结语），认证面板有副标题；登录方式写「密码登录」；字段标签与占位符重复；
验证码表单下有「未注册的手机号 / 邮箱将自动创建账号」；短信发码提示带内部编号 `product#seq`；按钮悬停提示会拼成「使用用 Chat 登录登录」。

## 需求

1. 居中一张认证面板：品牌行（BGSSAI 短剧）→ 装饰动效 → 标题「欢迎回来」→ 一排三个登录方式 `密码` / `邮箱验证码` / `手机验证码`（默认手机验证码）→ 表单 + 主按钮 → 第三方登录区 → 一行法律同意。去掉左侧营销栏与副标题。
2. 字段名只给读屏，输入框只显示占位符：`手机号 / 邮箱 / 账号`、`请输入密码`、`请输入邮箱地址`、`6 位验证码`。密码登录先按账号匹配，未命中且标识含 `@` 时再按邮箱匹配。
3. 密码主按钮「登录」；两种验证码主按钮「登录 / 注册」；去掉「未注册…将自动创建账号」。
4. 邮箱与手机各自一个重发倒计时，切换方式不互相影响；发码提示只写「验证码已发送」。
5. 第三方区只画已开通渠道，一个都没有时整段不出现；按钮不带悬停提示。
6. Bgssai Bot 下载是页面顶部常驻导航（`bot-download-entry.md`）。

## 验收

1. 1280 与 390 宽度下只有一张认证面板，没有左侧营销栏与副标题；登录方式标签为「密码 / 邮箱验证码 / 手机验证码」。
2. 手机发码后切到邮箱验证码，邮箱的「获取验证码」可用；切回手机倒计时仍在走；提示不含 `#` 编号。
3. 全部渠道未开通时第三方区（含分隔线）不出现。
4. 同意句在认证卡片内换行，不把协议链接顶出卡片。空提交只在没通过的字段下给出一条提示：密码页账号为空时，文案是「请输入账号」，写在账号框下。同一句不再另出顶部提示，也不在主按钮下再写一遍。
5. 两个汉字的按钮中间不自动插入空格。主按钮文案仍是「登录」或「登录 / 注册」。
6. 英文入口 `/en`、`/en/`、`/en/*` 转到中文登录页 `/login`，地址不再停在 `/en`。查询串和 hash 保留。
