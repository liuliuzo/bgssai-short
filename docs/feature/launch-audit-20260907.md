# 视频生成结果下载修复

版本：2026-09-07。上线审查缺陷修复。

1. Veo 异步生成完成后，Google API 文件下载必须携带对应 API Key。可下载视频不能因为下载阶段缺少鉴权而丢失。
2. 供应商文件重定向必须跟随有限次数并验证最终为成功状态；不能把 302 页面当作视频保存。跨来源跳转不转发供应商凭据。
3. 生成任务轮询只访问配置供应商的同来源地址，禁止将鉴权头发送到响应中任意外部地址。

验收：上述失败场景应有明确的失败反馈；成功结果必须来自真实有效的状态。已有登录、授权和业务权限规则仍适用。

## 任务结算一致性

未知任务类型必须失败，不能不生成内容就扣费。模型网络调用完成后，任务成功状态、本地钱包扣减、用量流水和作品成本必须在一个数据库事务中提交；已取消任务不再扣款。作品成本使用数据库原子累加。中央账本同步使用同事务写入的持久待发送记录，并以任务唯一标识幂等重试，避免本地回滚而中央已扣款。此修复覆盖结算事务，媒体生成过程中提前写入的素材和并发取消清理仍需后续审查。
