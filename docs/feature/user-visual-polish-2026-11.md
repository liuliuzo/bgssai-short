# 用户端视觉整理（2026-11-04）

用户原话：「美化一下所有项目的页面，现在的页面都太丑了」，随后点名包括 bgssai-short。

这是视觉与布局调整：不改账号、表单字段、接口、枚举、页面跳转、业务规则或数据库。
原型（`docs/demo-static`）只约束字段、状态与跳转，不约束外观，本次不改原型；正式 React 页面即视觉验收对象。
做法与境内 Chat 用户端（bgssai-chat-cn 2026-11-03 视觉整理）一致，颜色和控件对齐现行官网（bgssai-website 的 `public/site/site.css`）。

## 改了什么

### 全站

- 颜色：品牌蓝主按钮（#0d6efd）、深色字、浅灰底、白色实底卡片。去掉蓝紫色光斑底和半透明毛玻璃（卡片叠在彩色底上发虚，模糊效果每个页面都在后台重绘，手机上费电）。
- 用户端不再引用 `liquid-glass.css`；旧令牌名（`--brand`、`--lg-*`、`--lg-glass-*`）保留，值改成实底，各页面样式不用改名。管理端不受影响。
- Ant Design 主题与官网同色、同字体，控件高度统一 36px，表头、弹窗、下拉菜单改为实底；区号下拉面板改白色实底。

### 登录 / 下载页

- 顶栏左侧由「Bgssai Bot」改为品牌标志 + 「短剧 Short」（以前像打开错了产品）；右侧下载入口改描边按钮、带下载图标，文字不变。
- 登录内容放进一张白色卡片；登录方式切换改为灰底分段条；输入框、发送验证码按钮加高，主按钮纯品牌蓝；第三方登录按钮改白底描边。

### 登录后的页面外壳

- 侧栏白底，未选中的菜单用深灰字，当前页蓝底高亮；去掉侧栏里「用户端」这行端名。
- 顶栏显示当前页面名（以前固定写「AI 短剧制作平台」加一个「用户」标签）。
- 手机浏览器（宽度 ≤767px）改用和 Bot 旁栏相同的底部标签栏（首页 / 作品 / 任务 / 套餐 / 更多）：以前手机上 220px 侧栏常驻，内容区只剩一窄条，标题被挤成一字一行。菜单项和跳转都没变，「更多」里是其余菜单和退出登录。
- 在线客服按钮同品牌蓝；手机上抬到底部标签栏上方，不压住导航。

## 没改的

- 接口、字段、跳转、业务规则、数据库都没改；除顶栏标题外文案未改。
- 管理端（`bgssai-short-admin`）没动，`docs/demo-static` 原型没动。

## 验收

- 生产构建通过；前端已有的单元测试结果与改动前一致。
- 本地用假数据截图核对：登录、首页、我的作品、任务中心、用量与账单、套餐与加量、账号设置、MCP 连接器、下载、404，桌面 1440 与手机 390 两种宽度。

## 2026-11-04 补充：字体

用户补充：「字体也是美观的一部分」。

- 字体顺序改为英文和数字用系统界面字体（苹果 SF、Windows Segoe UI），中文用苹方 / 微软雅黑 UI。以前中文字体排在最前，Windows 上英文和数字也套用微软雅黑的西文字形，又宽又糊。
- 标题不再压紧字距，超粗字重收回为粗体；表格、统计数字等宽对齐。
- 只换字体与排版，不改文案和布局。
