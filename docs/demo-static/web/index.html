AI 短剧制作平台 web 端原型 — 概览

web 端按角色端拆为管理端与用户端两套独立原型，各自维护自己的 index.html（概览入口）与 PAGE-FLOW.html（跳转唯一真值），共享 assets/theme.css（全产品线标准主题）与 assets/short.css（本产品补充样式）。 原型是接口 JSON 字段命名（snake_case）、响应结构、枚举 / 状态值与页面跳转关系的权威参照， 前后端实现逐字对齐。当前用户端 11 页（制作主线 + 账户）、管理端 9 页（平台控制面）。

角色端入口

端目录工程 / 端口角色入口
管理端 web/admin/ bgssai-short-admin，后端 8080 / 前端 3001 PLATFORM_ADMIN 概览 · 跳转真值
用户端 web/user/ bgssai-short-user，后端 8080 / 前端 3002 USER 概览 · 跳转真值

共用约定

响应封装
{ code, message, success, result }，分页附 page_num / page_size / total_size
鉴权
请求头 Jwttoken
字段命名
一律 snake_case
其它端
移动端原型见 docs/demo-static/ios/ 与 docs/demo-static/android/（仅用户端）
