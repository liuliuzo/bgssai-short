收款商户

路径对齐 VPN：POST /bgssai/admin/pay/wechat-configs/save · POST /bgssai/admin/pay/alipay-configs/save；指定收款 POST .../set-collection-active。

  • 微信 Native：mch_id 唯一；空白凭据保留原值；同号软删行复活。生产必填 merchant_serial_no / api_v3_key / mch_private_key / notify_url。key_mode=PUBLIC_KEY 时另须 wechat_public_key_id 与 wechat_public_key，下单用该公钥验签，不下载平台证书。
  • 支付宝当面付：app_id 唯一；sign_type 仅 RSA2；必填 app_private_key / alipay_public_key / notify_url。
  • 同渠道至多一行 is_collection_active=1。生产无收款商户或凭据不全时用户下单返回 60013。
  • 支持配置默认收款商户与网关环境；支付宝商户 AppID 示例：2021006196627810。
