AI 短剧制作平台 web 管理端原型 — 概览

本目录是 AI 短剧制作平台 web 管理端（bgssai-short-admin，后端 8080 / 前端 3001， role_code=PLATFORM_ADMIN）原型与页面跳转的权威参照：接口 JSON 字段命名 （snake_case）、响应结构、枚举 / 状态值与页面跳转关系，前后端实现逐字对齐。本端跳转真值见 PAGE-FLOW.html；用户端原型见 ../user/index.html。

页面清单

页面路由对应接口说明需求
登录页 /login POST /bgssai/admin/login 账号密码登录，签发 JWT；非 PLATFORM_ADMIN 返回 4003 骨架内置
首页 /home -（消费登录响应缓存的身份字段） 今日待办、平台指标、职责边界、全部入口 骨架内置
内容审核队列 /reviews GET /bgssai/admin/reviews/list 以剧集为单位的待审队列，按提交时间正序，支持风险 / 题材 / 关键词筛选 content-compliance
审核详情与处置 /reviews/:review_id GET /bgssai/admin/reviews/detail · POST /approve · /reject 成片、台词全文、预检命中、处置历史；驳回必填原因与风险类别 content-compliance
AI 能力与模型配置 /ai-models GET /bgssai/admin/ai-models/list · POST /create · /update · /set-default · /toggle-enabled 按能力类型配供应商 / 模型 / 单价 / 质量档 / 开关，改配置即生效 ai-capability-usage
结构模板与质量阈值 /quality-templates GET /bgssai/admin/quality/templates/list · POST /threshold-save 爆款节拍模板库、四道门阈值、多方案版本数、分歧告警线 quality-pipeline
平台用量与成本 /usage-cost GET /bgssai/admin/usage/summary · /by-creator 按能力 / 按创作者 / 按日的用量、成本、成功率、平均耗时与对账口径 ai-capability-usage
创作者账号与配额 /creators GET /bgssai/admin/creators/list · POST /adjust-quota · /toggle-enabled 余额与月度上限维护，调整必填备注并写 quota_change_log ai-capability-usage
加量包目录 /credit-packs GET /bgssai/admin/credit-packs/list · POST /bgssai/admin/credit-packs/save 加量包目录价与启用状态 subscription-credit

登录日志 /login-logs GET /bgssai/admin/login-logs 示例分页列表（全量记录），消费 PageResponse 骨架内置

本端约定

工程
bgssai-short-admin，后端 8080 / 前端 3001
角色
role_code=PLATFORM_ADMIN（其它角色不得登录本端）
登录接口
POST /bgssai/admin/login
对内容的权限
只读——只给审核结论与平台配置，不修改创作者的剧本 / 镜头 / 素材
响应封装
{ code, message, success, result }，分页附 page_num / page_size / total_size
鉴权
请求头 Jwttoken；角色取自 JWT，不取自请求参数（零信任）
金额口径
接口字段一律以分为单位（*_cent），页面展示为元
枚举字典
见 docs/feature/short-work-management.md 第八节（单一登记处）
样式
../assets/theme.css（标准主题）+ ../assets/short.css（本产品补充）
