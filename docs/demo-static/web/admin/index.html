AI 短剧制作平台 web 管理端原型 — 概览

本目录是 AI 短剧制作平台 web 管理端（bgssai-short-drama-admin，后端 8080 / 前端 3001， role_code=PLATFORM_ADMIN）原型与页面跳转的权威参照：接口 JSON 字段命名 （snake_case）、响应结构、枚举 / 状态值与页面跳转关系，前后端实现逐字对齐。本端跳转真值见 PAGE-FLOW.html；用户端原型见 ../user/index.html。

页面清单

页面路由对应接口说明
登录页 /login POST /bgssai/admin/login 账号密码登录，签发 JWT；非 PLATFORM_ADMIN 返回 4003
首页 /home - 展示当前登录身份
登录日志 /login-logs GET /bgssai/admin/login-logs 示例分页列表（全量记录），消费 PageResponse

本端约定

工程
bgssai-short-drama-admin，后端 8080 / 前端 3001
角色
role_code=PLATFORM_ADMIN（其它角色不得登录本端）
登录接口
POST /bgssai/admin/login
响应封装
{ code, message, success, result }，分页附 page_num / page_size / total_size
鉴权
请求头 Jwttoken
