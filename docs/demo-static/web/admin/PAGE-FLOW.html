三、导航不变量（逐条强制，CR 核对）

  1. 列表必达详情：审核队列每一行可进审核详情；用量分创作者列表每行可进创作者管理； 模型列表每行可编辑。严禁假可点。
  2. 详情必可返回：审核详情顶部常驻「返回审核队列」与面包屑。
  3. 无死胡同：每个页面都可经品牌 logo 或面包屑首项回到 /home。
  4. 无孤岛：除登录页外，每个页面在路由矩阵「主要入口」列都有至少一个站内父级入口。
  5. 全局导航外壳常驻：顶部导航栏（内容审核 / AI 能力 / 结构模板 / 用量与成本 / 创作者 / 登录日志 + 头像）与面包屑在所有页面常驻。
  6. 权限态分支：本端只允许 role_code=PLATFORM_ADMIN，其它角色登录返回 4003；角色一律取自 JWT，不取自请求参数（零信任）。
  7. 只读边界：管理端对创作内容只读——不提供任何编辑创作者剧本 / 镜头 / 素材的入口， 只提供审核结论与平台配置入口。
  8. 必填留痕：驳回必填原因与风险类别、调整配额必填备注，未填不放行（4006）； 审核与配额变更记录只增不删。
