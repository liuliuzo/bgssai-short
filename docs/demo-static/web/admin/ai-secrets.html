业务第三方凭证落 sys_secret（明文开发期口径）。中间件参数仍写 application-*.properties。演示前至少配置 ai.tokenhub_cn.api_key （兼容旧键 ai.tencent_tokenhub.api_key）与 ai.kling.api_key。 短剧业务仅启用境内模型网关密钥。 「测试」只检查密钥非空已启用，不向供应商发扣费请求。

ai.* 密钥清单

密钥键说明已配置掩码启用操作
ai.tokenhub_cn.api_key 境内模型网关 Bearer 凭证 否 是
ai.tokenhub_global.api_key 境外模型网关（短剧停用，不作为回退） 否 否
ai.kling.api_key 可灵 Bearer 否 是
字段口径
接口：GET /bgssai/admin/secrets/list?key_prefix=ai. （secret_list[secret_key · description · configured_flag · secret_value_masked · enabled]）· POST /bgssai/admin/secrets/update （secret_key · 可选 secret_value / enabled / description）· POST /bgssai/admin/secrets/test （返回 ok · configured_flag · message）。 仅允许 ai.* 键；响应永不回显明文密钥。
