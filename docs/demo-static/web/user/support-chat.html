在线客服（悬浮 · 对话气泡 + 提工单）

USER / GUEST

导航：首页 · 登录 · 在线客服

契约摘要

UX：打开 → 气泡区 + 底部输入；首条留言 create 建会话；无联系方式 / 主题前置表单；工具栏可提工单。

创建：POST /bgssai/user/support/sessions/create body {guest_token?, content}（API 仍兼容可选 contact_*，访客 UI 不采集）

我的会话：POST /bgssai/user/support/sessions/mine

详情：POST /bgssai/user/support/sessions/detail body {session_id, guest_token?} → 含 ticket

发消息：POST /bgssai/user/support/messages/send body {session_id, guest_token?, content}

提工单：POST /bgssai/user/support/tickets/create body {session_id, guest_token?, subject?, category?, priority?, description?}

会话状态：OPEN / PENDING / CLOSED；工单：OPEN / IN_PROGRESS / RESOLVED / CLOSED。
