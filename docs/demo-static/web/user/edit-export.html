三种格式怎么选

剪映草稿
国内短剧主力工具。视频轨、配音轨、字幕轨、BGM 轨全带上，字幕是可编辑文本不是烧死的图。
FCPXML
达芬奇调色、Final Cut 精剪走这条。带 title 文本元素，字幕进去还能改。
EDL
最老实的交换格式，几乎所有剪辑软件都认。但它只有剪辑点没有文本轨，所以包里另附一份 SRT。

导出不会动到什么

成片状态
不变（不置过期）
审核结论
不变（不回落）
镜头状态
不变（不解锁、不打回）
账单
不产生用量记录
配额
不扣余额
导出是只读动作：把已有素材换个封装拿走，不参与创作状态机。
