连接 AI 工具

为 Claude / Codex / Cursor / Grok Bot / BGSSAI Bot 配置同一 MCP 端点 POST /api/mcp。先创建令牌，再按工具粘贴配置。支持作品与原创剧本、正式分镜和参考图定妆、模型与声音目录、角色声音设置、图像/视频/配音/音乐/合成（需费用确认）、任务状态及真实成片下载；对外发布另需确认。另可查询本人登录日志与健康探针。

角色、场景和道具参考图均可先保存外观或布景描述；候选完成后待用户选择，未锁定的引用不会被视为可生成。

制作顺序：保存场次 → 剧本定稿 → 参考图定妆与角色声音设置 → 拆分与保存分镜（逐镜说话者优先绑定） → 图像/视频/配音/音乐 → 下载验收并明确锁定镜头 → 合成预检 → 成片 MP4。分镜替换须明确确认；每次生成均可能计费，不自动重试。

28 个工具中，get_asset_download 输入 {asset_id}，仅返回本人资产的 download_url 与 expire_at，可检查首帧、视频和配音；到期重新查询。

resume_video_task 仅输入 {task_id}，恢复已提交的本人公司视频任务。依据唯一持久回执查询已有视频，不再次生成；缺失、重复、凭据变化或已有后续视频时拒绝。原任务仍按正式流程结算。

regenerate_subtitles 输入 {episode_id, confirm_replace: true}，从已有配音与分镜重建本人分集字幕，会替换现有字幕（包括人工编辑）。只接受 boolean true；无模型任务或生成费用，不自动重新合成。

检查镜头视频后，调用 lock_shot，输入 {episode_id, shot_id, confirm_review: true}。只接受 boolean true；镜头须属于本人同一分集，已有视频且状态为 VIDEO_READY 或 LOCKED。不接收资产覆盖、不自动生成或发布；锁定后仍须完整合成预检。

查询工具 get_render_task 返回本人任务状态与错误；get_episode_film 返回真实下载地址、过期状态、字幕及配音预检。未完成成片不会显示占位下载。

查询 API：POST /api/mcp/tokens/list（需请求头 Jwttoken）

动作 API：POST /api/mcp/tokens/create body {token_name}； POST /api/mcp/tokens/revoke body {id}

MCP 端点鉴权：Authorization: Bearer bgs_mcp_...

{
  "mcpServers": {
    "bgssai-short": {
      "url": "https://<域名>/api/mcp",
      "headers": { "Authorization": "Bearer bgs_mcp_你的令牌" }
    }
  }
}
