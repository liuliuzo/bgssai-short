连接 AI 工具

为 Claude / Codex / Cursor / Grok Bot / bgssai-bot 配置同一 MCP 端点 POST /api/mcp。先创建令牌，再按工具粘贴配置。当前工具仅登录日志与健康探针。

查询 API：POST /bgssai/mcp-tokens/list（需请求头 Jwttoken）

动作 API：POST /bgssai/mcp-tokens/create body {token_name}； POST /bgssai/mcp-tokens/revoke body {id}

MCP 端点鉴权：Authorization: Bearer bgs_mcp_...

Claude

claude mcp add --transport http bgssai-short https://<域名>/api/mcp \
  --header "Authorization: Bearer bgs_mcp_你的令牌"

Codex

codex mcp add bgssai-short --url https://<域名>/api/mcp \
  --header "Authorization: Bearer bgs_mcp_你的令牌"

Cursor

{
  "mcpServers": {
    "bgssai-short": {
      "url": "https://<域名>/api/mcp",
      "headers": { "Authorization": "Bearer bgs_mcp_你的令牌" }
    }
  }
}

Grok Bot

MCP URL:  https://<域名>/api/mcp
Auth:     Authorization: Bearer bgs_mcp_你的令牌
Transport: Streamable HTTP (POST)

bgssai-bot

MCP URL:  https://<域名>/api/mcp
Auth:     Authorization: Bearer bgs_mcp_你的令牌
Transport: Streamable HTTP (POST)
