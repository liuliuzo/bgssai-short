字段口径
大纲行即 episode_title + episode_synopsis + ending_hook （保存走 POST /bgssai/user/scripts/outline-save）；梗概重写触发 POST /bgssai/user/scripts/outline-generate——执行前展示影响范围与费用 （只重写大纲行，不覆盖已定稿集的正文）；无大纲空态下顶部按钮文案为「生成大纲」， 已有大纲才是「重新生成大纲」。顶部文本模型来自 GET /bgssai/user/ai-models/list?ability_type=TEXT（选项展示 display_name，不含中枢名 / provider_code），大纲、剧本生成与局部重写提交 model_code，省略或不可用时由后端回退默认模型。展开的剧本即 scene_list （POST /bgssai/user/scripts/save · /generate · /rewrite）， 定稿走 POST /bgssai/user/scripts/ready 并自动拆镜进创作台； 定稿后仅错别字级文字修改（不改变场次与台词切分）不回落 storyboard_status。 行内提示来自集间衔接检查（episode_gap_type=HOOK_MISMATCH 等）与合规预检 （POST /bgssai/user/compliance/precheck，check_scope=SCRIPT： 命中片段高亮 + risk_category 中文 + 改写建议 + 「采纳改写」），仅在有问题时出现； 「定稿」按钮旁展示剧本门（G1_SCRIPT）与预检状态徽标（中文）。 「历史版本」抽屉复用 GET /bgssai/user/scripts/versions 与 POST /bgssai/user/scripts/rollback。 节奏体检 / 三视角评审等其余进阶能力收在「更多功能」， 需求见 docs/feature/script-studio.md 与 ux-three-questions.md。
