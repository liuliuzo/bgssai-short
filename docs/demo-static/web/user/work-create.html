字段口径
接口 POST /bgssai/user/short-works/create（POST 业务参数走 JSON Body）， 必填仅 work_title 与 one_line_pitch（梗概必填，提交即产生一条 task_type=TEXT 的大纲生成任务），返回 work_id。 高级设置字段（genre / episode_count / episode_duration_sec / visual_style / template_id） 省略走默认值；下拉选项只显示中文文案，枚举值收在 value 属性。 创建流程不含预算与质量阈值：cost_budget_cent 是作品设置里的可选项（默认不限）， quality_threshold_score 由结构模板给默认、创建后可随时调整（调整留痕）。 模板列表取自 GET /bgssai/user/quality/templates?genre。
