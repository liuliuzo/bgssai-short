AI 短剧制作平台 web 用户端原型 — 概览

本目录是 AI 短剧制作平台 web 用户端（bgssai-short-user，后端 8080 / 前端 3002， role_code=USER）原型与页面跳转的权威参照：接口 JSON 字段命名（snake_case）、 响应结构、枚举 / 状态值与页面跳转关系，前后端实现逐字对齐。本端跳转真值见 PAGE-FLOW.html；管理端原型见 ../admin/index.html。

制作主线（按流程顺序）

页面路由对应接口说明需求
我的作品 /works GET /bgssai/user/short-works/list 作品列表，按状态 / 题材过滤，走 PageResponse short-work-management
新建作品 /works/create POST /bgssai/user/short-works/create 三步向导：基本信息 → 结构模板 → 预算；填了梗概自动触发大纲生成 short-work-management · quality-pipeline
作品工作台 /works/:work_id GET /bgssai/user/short-works/detail 剧集看板：六阶段徽标 + 质量分 + 四道门状态 short-work-management
总剧本 /works/:work_id/script POST /bgssai/user/scripts/generate · /rewrite · /ready 分集大纲 + 场次台词 + 节奏体检 + 版本回滚 script-studio
剧情 /works/:work_id/story-map GET /bgssai/user/story-map/tension · /relations · /blocking 张力曲线、人物关系图、走位示意、场次时间带、出场热力；零成本看出节奏与空间问题 story-map
角色与场景卡 /works/:work_id/characters POST /bgssai/user/characters/portrait-generate · /lock 一次定妆全剧锁定；场景卡 / 道具卡同构；一致性面板把三类资产绑到镜头 character-bible · asset-consistency-panel
分镜 /works/:work_id/storyboard GET /bgssai/user/shots/list · POST /bgssai/user/previz/update · /draft-generate · /promote · POST /bgssai/user/ai-tasks/submit 核心页（分镜 + 文字预演合并）：每镜左文字右画面一一对应，改文字免费，一个按钮逐级生成（草图 → 首帧 → 视频） storyboard-workbench · previz-text-storyboard
AI 协同专家抽屉 /works/:work_id/:tab（抽屉） POST /bgssai/user/drama-assist/advise · POST /bgssai/user/drama-assist/apply 作品页右侧多专家建议；走 CN TEXT；确认后写回镜头字段 drama-assistant-experts
任务中心 /works/:work_id/tasks POST /bgssai/user/ai-tasks/estimate · /submit · /retry 批次进度、失败重试、断点续跑、费用累计与计费口径 shot-generation
配音与字幕 /works/:work_id/voice POST /bgssai/user/dubbings/submit · /align 角色音色绑定、逐镜配音、音画对齐三解法、字幕与样式 voice-subtitle
合成与导出 /works/:work_id/compose GET /bgssai/user/films/precheck · POST /bgssai/user/films/compose 前置检查、四轨时间轴（只读）、一键合成、多版本导出、提交审核 film-compose-export · content-compliance
分镜画布 /works/:work_id/storyboard?view=canvas GET /bgssai/user/shots/list · POST /bgssai/user/shots/reorder 整集按场次分行一屏看完，颜色即状态；框选一段整组估费用与重跑；场内拖拽改镜号 storyboard-canvas
原著导入与改编 /works/:work_id/source POST /bgssai/user/sources/import · /adapt 小说 / 成品剧本 / 分集大纲三种源导入，自动分章可纠正，按章改编出带出处的大纲 source-import
剪辑工程导出 /works/:work_id/edit-export GET /bgssai/user/edit-projects/precheck · POST /bgssai/user/edit-projects/export 剪映草稿 / FCPXML / EDL 三种工程格式，素材可打包可只出清单，缺片镜头列名并留空档 edit-project-export
看样片 /works/:work_id/preview GET /bgssai/user/preview/summary（帧序列复用 previz / shots 接口） 问题一「我的视频会是什么样子」：文字 + 草图把整集当成片看一遍，零视频费用，只读 ux-three-questions
连贯性中心 /works/:work_id/continuity GET /bgssai/user/continuity/overview · /foreshadows 问题二「我的剧情连不连贯」：全剧 / 集间 / 镜头三层问题一张清单 + 伏笔台账 ux-three-questions
质量 /works/:work_id/quality POST /bgssai/user/quality/gate-run · GET /bgssai/user/quality/gate-result 四道门 + 三视角评审团 + 定点返工清单 + 多方案择优 + 质量档案 quality-pipeline

账户与基础页

页面路由对应接口说明
壳内窄栏 布局模式（复用既有路由 + ?bgssai_shell=1） 无新接口 Bot 对话旁触控窄栏；独立桌面不套用
登录页 /login POST /bgssai/user/login 账号密码登录，签发 JWT；本端不做角色门禁，启用中的账号均可登录
首页 /home GET /bgssai/user/short-works/list · /detail · GET /bgssai/user/ai-tasks/list 下一步、最近作品继续创作、待处理深链；无作品时只有新建作品
用量与账单 /usage GET /bgssai/user/usage/summary · /records 余额、本月消耗、按作品 / 按能力聚合、流水下钻到镜头
套餐与加量 /subscription GET /bgssai/user/subscription/plans · /me · POST /bgssai/user/subscription/order/create · GET /bgssai/user/credit-packs · POST /bgssai/user/credit-packs/orders 订阅套餐与加量包；展示到期与 token 额度（K/M/B）；微信 / 支付宝扫码；回调入账
账号设置 /account GET /bgssai/user/account/login-methods · POST .../bind-* · .../unbind · .../deletion 登录方式绑定解绑；账号注销；移动端同入口
登录日志 /login-logs GET /bgssai/user/login-logs 示例分页列表（仅本人记录，user_id 取自 JWT）
MCP 连接器 /mcp-tokens POST /api/mcp/tokens/create · /list · /revoke MCP Connectors（Claude / Codex / Cursor / Grok Bot / Bgssai Bot）；tagline「Connect your AI tools to bgssai」；PAT 管理；客户端调用 POST /api/mcp
在线客服 全局悬浮 POST /bgssai/user/support/sessions/create · /mine · /detail · POST /bgssai/user/support/messages/send 对话气泡：打开即气泡+底部输入，首条建会话；无前置联系方式表单；访客 guest_token

本端约定

工程
bgssai-short-user，后端 8080 / 前端 3002
角色
role_code=USER
登录接口
POST /bgssai/user/login
数据可见范围
仅本人数据；user_id 一律取自 JWT，不从请求参数取
响应封装
{ code, message, success, result }，分页附 page_num / page_size / total_size
鉴权
请求头 Jwttoken
金额口径
接口字段一律以分为单位（*_cent），页面展示为元
枚举字典
见 docs/feature/short-work-management.md 第八节（单一登记处）
样式
../assets/theme.css（标准主题）+ ../assets/short.css（本产品补充）
法律页
登录 + 页脚双语外链官网五页；不托管正文、不编造证照号。需法务审阅。见 docs/feature/legal-fan-out.md
