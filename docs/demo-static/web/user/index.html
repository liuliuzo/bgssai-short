AI 短剧制作平台 web 用户端原型 — 概览

本目录是 AI 短剧制作平台 web 用户端（bgssai-short-drama-user，后端 8081 / 前端 3002， role_code=USER）原型与页面跳转的权威参照：接口 JSON 字段命名（snake_case）、 响应结构、枚举 / 状态值与页面跳转关系，前后端实现逐字对齐。本端跳转真值见 PAGE-FLOW.html；管理端原型见 ../admin/index.html。

页面清单

页面路由对应接口说明
登录页 /login POST /bgssai/user/login 账号密码登录，签发 JWT；本端不做角色门禁，启用中的账号均可登录
首页 /home - 展示当前登录身份
登录日志 /login-logs GET /bgssai/user/login-logs 示例分页列表（仅本人记录，user_id 取自 JWT），消费 PageResponse
MCP 接入 /mcp-tokens POST /bgssai/mcp-tokens/create · /list · /revoke 个人访问令牌管理；AI 客户端调用 POST /api/mcp（Bearer PAT）

本端约定

工程
bgssai-short-drama-user，后端 8081 / 前端 3002
角色
role_code=USER
登录接口
POST /bgssai/user/login
数据可见范围
仅本人数据；user_id 一律取自 JWT，不从请求参数取
响应封装
{ code, message, success, result }，分页附 page_num / page_size / total_size
鉴权
请求头 Jwttoken
