计费

不计费
失败与已取消不计费；平台侧原因（模型超时、供应商故障）触发的自动重试不计费
自动重试
失败按指数退避重试至多 2 次；仍失败按原因分类（超时 / 内容拦截 / 素材缺失），列表里直接给对应动作
在途上限

暂停恢复
批次可随时暂停：排队任务原地保留，执行中的跑完当前不中断；恢复原位续跑，不重走提交、不重复扣费
断点续跑
任务落库执行，与浏览器连接无关；重进页面按批次恢复视图
预算触顶
作品累计触及预算 100% 时剩余排队任务自动暂停并提示，一键「提高预算并恢复排队」，不静默烧完余额
