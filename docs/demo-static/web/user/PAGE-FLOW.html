跳转规则

  • 访问 / 自动重定向到 /home（已登录）或 /login（未登录）。
  • 受保护路由（/home、/login-logs、/mcp-tokens）要求已登录且 role_code=USER，否则跳回 /login。
  • 已登录用户访问 /login 自动跳回 /home。
  • 接口返回 code=2002（token 失效 / 上下文无身份）时前端清理身份并跳回 /login； code=4003（角色不符）同样提示后跳回登录。两者均为 HTTP 200 + 封装内 code， 前端只看 code。
  • 本端所有列表 / 详情只呈现当前登录用户本人数据，越权访问由后端按 JWT 中的 user_id 过滤（不依赖前端隐藏入口）。
