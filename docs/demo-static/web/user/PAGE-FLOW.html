三、导航不变量（逐条强制，CR 核对）

  1. 列表必达详情：作品列表每一行可进作品工作台；剧集看板每一集可进对应工作台； 镜头网格每一镜可开详情面板；任务列表每条可回到其目标对象；流水每条可下钻到作品 / 剧集 / 镜头。严禁假可点。
  2. 详情必可返回：所有二级页面顶部常驻「返回作品工作台」与面包屑，可层层返回。
  3. 无死胡同：每个页面都可经品牌 logo 或面包屑首项回到 /home。
  4. 无孤岛：除登录页外，每个页面在路由矩阵「主要入口」列都有至少一个站内父级入口。
  5. 全局导航外壳常驻：左侧导航统一为同一套结构—— 「首页 / 三个问题（看样片、连贯性中心、剧集看板）/ 当前工作（我的作品、总剧本、创作台）/ 任务中心 / 更多（折叠：角色与场景卡、配音与字幕、合成与导出、质量报告、剧情图谱、 用量账单、账户）+ 当前身份与余额」，首页、我的作品、作品工作台、总剧本、创作台五个主页面 逐字一致；顶部面包屑在所有页面常驻；作品内子页面另有一条 作品级阶段导航（剧集看板 / 剧本 / 角色定妆 / 创作台 / 画面生成 / 配音字幕 / 合成导出 / 质量报告），保证作品内可横向直达、无需回退。
  6. 权限态分支：本端仅 role_code=USER；入口按身份渲染，权限不足不渲染入口而非渲染后报 403。 后端仍按 JWT 中的 user_id 独立做数据范围过滤，不因前端隐藏入口而放宽。
  7. 阻塞态入口禁用而非隐藏：合成前置条件不满足、镜头被合规拦截、门禁未达标时， 对应按钮禁用并给出可读原因与直达修复链接，不静默隐藏——用户必须知道自己卡在哪。
  8. 只读态：剧集提交审核后其编辑入口整体转只读（撤回后恢复）， 避免「审核中的内容仍在被改」。
