余额预警与批量保护

余额低于近一集均价的 3 倍（当前口径 321.60 元）时，本页与任务提交处提前预警。 批量任务预估超出余额时不整批拒绝，而是按预估单集成本提示 「按当前余额可先做前 X 集」，先做起来再补余额。
字段口径
接口：GET /bgssai/user/usage/summary?start_date&end_date （含 recent_episode_avg_cost_cent 近期单集均价 · estimated_remaining_episode_count 约还能做 N 集 · 余额低于近一集均价 3 倍时预警）· /records?page_num&page_size&work_id&episode_id&ability_type&start_date&end_date （传 episode_id 时返回 episode_total_cost_cent 本集累计成本）； POST /bgssai/user/recharge/apply · GET /bgssai/user/recharge/list （recharge_apply_status：SUBMITTED 已提交 / PROCESSING 处理中 / COMPLETED 已完成 / REJECTED 已驳回）。 流水字段：record_id · ability_type（TEXT 文本 / IMAGE 图像 / VIDEO 视频 / VOICE 配音 / COMPOSE 合成）· model_code · quality_level（FAST 快速 / STANDARD 标准 / HIGH 高质，即行内档位标注）· price_unit（PER_CALL / PER_SECOND / PER_KILO_TOKEN / PER_MINUTE）· usage_amount · unit_price_cent（单价快照，不随调价变化）· cost_cent · work_id / episode_no / shot_no / task_id。 页面正文一律用中文标签，英文枚举值收在本区与元素 title 提示中。 流水只读；FAILED 任务不产生流水，平台侧自动重试不额外计费。 批量任务预估超余额时返回 affordable_episode_count（可先做前 X 集）。
