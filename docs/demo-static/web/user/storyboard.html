每行文字即 previz_text（可编辑，保存走 POST /bgssai/user/previz/update， 系统自动派生提示词并保证角色一致性）；右侧画面为该镜 previz_level 当前级素材， 按钮指向下一级（/previz/draft-generate · /promote · /ai-tasks/submit）。「全部生成」走 POST /bgssai/user/previz/draft-generate（target_level 取 DRAFT_IMAGE / IMAGE / VIDEO + 可选 auto_continue_video_flag），提交前返回费用预估。 行内提示来自连贯性检查、角色定妆状态与合规预检 （/previz/continuity-check、card_status、 POST /bgssai/user/compliance/precheck check_scope=SHOT： 命中片段高亮 + risk_category 中文 + 改写建议 + 「采纳改写」），仅在有问题时出现。 连贯性提示不阻塞生成（该镜生成按钮不禁用），可「忽略这条」——忽略留痕并计入分镜门 G2_STORYBOARD 评分；未定妆角色的镜头仍禁用生成（blocked_flag=1）。 顶部展示剧本门（G1_SCRIPT）与预检状态徽标（中文）。 列表 GET /bgssai/user/shots/list?episode_id。 进阶能力（剧本工作台 / 图谱 / 质量门 / 走位等）全部收在侧栏「更多」， 需求见 docs/feature/storyboard-workbench.md 与 previz-text-storyboard.md。
