字段口径
每行文字即 previz_text（可编辑，保存走 POST /bgssai/user/previz/update， 系统自动派生提示词并保证角色一致性）；右侧画面为该镜 previz_level 当前级素材， 按钮指向下一级（/previz/draft-generate · /promote · /ai-tasks/submit）。「全部生成」走 POST /bgssai/user/previz/draft-generate（target_level 取 DRAFT_IMAGE / IMAGE / VIDEO + 可选 auto_continue_video_flag），提交前返回费用预估。 右侧资产一致性面板走 GET /bgssai/user/assets/consistency-panel， 勾选镜头后 POST /bgssai/user/shots/bind-assets 写入 character_ref_json / scene_card_id / prop_ref_json。 列表另回 latest_task（统一任务状态机）。 行内提示来自连贯性检查、角色定妆状态与合规预检 （/previz/continuity-check、card_status、 POST /bgssai/user/compliance/precheck check_scope=SHOT： 命中片段高亮 + risk_category 中文 + 改写建议 + 「采纳改写」），仅在有问题时出现。 连贯性提示不阻塞生成（该镜生成按钮不禁用），可「忽略这条」——忽略留痕并计入分镜门 G2_STORYBOARD 评分；未定妆角色 / 场景 / 道具的镜头仍禁用生成（blocked_flag=1）。 顶部 VIDEO 模型来自 GET /bgssai/user/ai-models/list?ability_type=VIDEO，所选 model_code 随单镜或批量任务提交；存在首帧时由 Provider 走图生视频，否则走文生视频。 首尾帧衔接：镜头 frame_link_mode（NONE / INHERIT_PREV / BOOKEND）经 POST /bgssai/user/shots/frame-link-save 与 /frame-link-batch 维护， 列表返回 last_frame_asset_id · last_frame_url · link_effective_flag · link_hint； 跨场次自动降级（downgrade_reason=CROSS_SCENE）；单独出尾帧走 POST /bgssai/user/shots/last-frame-generate（target_type=LAST_FRAME）； 模型是否支持首尾帧取 ai_model_config.config_json.support_last_frame，不支持却设 BOOKEND 返回 4006。 需求见 frame-continuity.md。 顶部展示剧本门（G1_SCRIPT）与预检状态徽标（中文）。 列表 GET /bgssai/user/shots/list?episode_id。 进阶能力（剧本工作台 / 图谱 / 质量门 / 走位等）全部收在侧栏「更多」， 需求见 docs/feature/storyboard-workbench.md 与 previz-text-storyboard.md。
