字段口径
每行文字即 previz_text（可编辑，保存走 POST /bgssai/user/previz/update， 系统自动派生提示词并保证角色一致性）；右侧画面为该镜 previz_level 当前级素材， 按钮指向下一级（/previz/draft-generate · /promote · /ai-tasks/submit）。「全部生成」走 POST /bgssai/user/previz/draft-generate（target_level 取 DRAFT_IMAGE / IMAGE / VIDEO + 可选 auto_continue_video_flag），提交前返回费用预估。 右侧资产一致性面板走 GET /bgssai/user/assets/consistency-panel， 勾选镜头后 POST /bgssai/user/shots/bind-assets 写入 character_ref_json / scene_card_id / prop_ref_json。 列表另回 latest_task（统一任务状态机）以及 video_url、 first_frame_url、last_frame_url。 已有 video_url 的镜头在列表左侧直接播放，点击画面即可播放或暂停，播放框尺寸固定； 「放大播放」是按钮，放大层盖住工具条。没有视频时首帧、尾帧点击放大。 成片时长和 shot_duration_sec 不一致时标题写「成片 N秒 · 计划 M秒」，不把计划秒数说成成片长度，也不回写成片时长。 出图、视频模型展示完整名称（含「按任务实际对账」），可悬停读取。未勾选镜头的费用行带「额度」。 运镜 / 风格 / 视角 / 衔接写法分行；和上一镜只使用 frame_link_mode，link_hint 仍显示。 人话「在哪」：叙事里已有地点就用该地点，否则用已绑定场景卡名；不得在场景已知时仍写「在哪：未写清场景」。 画布、抽屉和配音表使用同一套场景、台词和成片/计划时长。 绑定下拉只显示人名、场景名和卡状态，选项文字不含角色编号或场景编号。 每一镜的操作和人话框随该卡片滚走，不粘在页面顶部。 页脚和在线客服不挡住首帧、人话或抽屉按钮。已有成片时首帧缩略图保持 72 宽，下方文案为「查看首帧」，单行排下，点击仍打开同一张图。 剧集芯片在非成片页与选择器同为剧本状态/审核状态，不因合成尚未开始而显示「未开始」。 顶部绑定下拉打开时为空，旁边列出本剧已有卡，不表示当前镜头没有引用。 镜头已是 VIDEO_READY 或 LOCKED，且 video_asset_id / video_url 仍在时， 不再把历史失败或取消的视频任务当成这一镜的常驻标签，不得显示「已有视频，本次重生成失败」，也不得显示成没有视频。 进行中的视频任务仍显示进度。状态尚未回到 VIDEO_READY 时，已有成片的刚失败尝试仍可提示。 任务中心仍保留失败记录，不删除、不解绑成片。画布不是唯一播放入口。 行内提示来自连贯性检查、角色定妆状态与合规预检 （/previz/continuity-check、card_status、 POST /bgssai/user/compliance/precheck check_scope=SHOT： 命中片段高亮 + risk_category 中文 + 改写建议 + 「采纳改写」），仅在有问题时出现。 连贯性提示不阻塞生成（该镜生成按钮不禁用），可「忽略这条」——忽略留痕并计入分镜门 G2_STORYBOARD 评分；未定妆角色 / 场景 / 道具的镜头仍禁用生成（blocked_flag=1，并由 shots/list 返回可读中文 block_reason 与「去角色定妆」直达入口）。 出草图与生成视频主工具条直接展开在分镜列表上方（含「勾选待生视频镜头」快捷勾选），手动改绑资产与独立单图试做收在辅助折叠区；官方视频 POST /bgssai/user/ai-tasks/official-video/submit 无论走图生视频还是文生视频均保持同一 batch_id，由 batch-progress 统一追踪并在完成后自动刷新列表。 顶部画面模型来自 GET /bgssai/user/ai-models/list?ability_type=IMAGE，未点选时默认 bgssai-image（BGSSAI Image）。VIDEO 模型来自 GET /bgssai/user/ai-models/list?ability_type=VIDEO，所选 model_code 为 bgssai-video，随单镜或批量任务提交，走原来的文生视频。图生视频是本页独立面板，不因存在首帧而改道。 未传 model_code 时，开发库解析到已启用的 bgssai-video（国内中枢，超时 900 秒），不落到 MiniMax 或 cogvideox。生产默认模型不因该种子改动。 公司文生视频一次只生成一条。画面提示词先写已锁定角色的外貌、服装、场景和道具。占位首帧或占位定妆图不会当作参考，也不会当作图生视频的原图。「生成视频」和「重新生成」在有真实 PNG 或 JPEG 时走图生视频，成片是 384×256、约 3 秒，不是 9:16；没有真实照片时改走文生视频，约 720×480、约 6 秒。重新生成先确认会计费，取消不提交、不删除当前成片。这一镜已在排队或执行中时不再开第二笔。图生视频不占文生视频的 GPU 车道。任务中心对还在后面的镜头显示排队中和前面还有几条，对正在生成的显示已等待时间。 页面与接口不展示网关编号。 首尾帧衔接：镜头 frame_link_mode（NONE / INHERIT_PREV / BOOKEND）经 POST /bgssai/user/shots/frame-link-save 与 /frame-link-batch 维护， 列表返回 last_frame_asset_id · last_frame_url · link_effective_flag · link_hint； 跨场次自动降级（downgrade_reason=CROSS_SCENE）；单独出尾帧走 POST /bgssai/user/shots/last-frame-generate（target_type=LAST_FRAME）； 模型是否支持首尾帧取 ai_model_config.config_json.support_last_frame，不支持却设 BOOKEND 返回 4006。 需求见 frame-continuity.md。 顶部展示剧本门（G1_SCRIPT）与预检状态徽标（中文）。
