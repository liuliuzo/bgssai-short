字段口径
每行文字即 previz_text（可编辑，保存走 POST /bgssai/user/previz/update， 系统自动派生提示词并保证角色一致性）；右侧画面为该镜 previz_level 当前级素材， 按钮指向下一级（/previz/draft-generate · /promote · /ai-tasks/submit）。「全部生成」走 POST /bgssai/user/previz/draft-generate（target_level 取 DRAFT_IMAGE / IMAGE / VIDEO + 可选 auto_continue_video_flag），提交前返回费用预估。 右侧资产一致性面板走 GET /bgssai/user/assets/consistency-panel， 勾选镜头后 POST /bgssai/user/shots/bind-assets 写入 character_ref_json / scene_card_id / prop_ref_json。 列表另回 latest_task（统一任务状态机）以及 video_url、 first_frame_url、last_frame_url。 已有 video_url 的镜头在列表左侧直接播放，点击画面即可播放或暂停，播放框尺寸固定； 「放大播放」是按钮，放大层盖住工具条。没有视频时首帧、尾帧点击放大。 成片时长和 shot_duration_sec 不一致时标题写「成片 N秒 · 计划 M秒」，不把计划秒数说成成片长度，也不回写成片时长。 出图、视频模型展示完整名称（含「按任务实际对账」），可悬停读取。未勾选镜头的费用行带「额度」。 运镜 / 风格 / 视角 / 衔接写法分行；和上一镜只使用 frame_link_mode，link_hint 仍显示。 人话「在哪」：叙事里已有地点就用该地点，否则用已绑定场景卡名；不得在场景已知时仍写「在哪：未写清场景」。 画布、抽屉和配音表使用同一套场景、台词和成片/计划时长。 绑定下拉只显示人名、场景名和卡状态，选项文字不含角色编号或场景编号。 每一镜的操作和人话框随该卡片滚走，不粘在页面顶部。 页脚和在线客服不挡住首帧、人话或抽屉按钮；首帧「点击查看」打开同一张图。 剧集芯片在非成片页与选择器同为剧本状态/审核状态，不因合成尚未开始而显示「未开始」。 顶部绑定下拉打开时为空，旁边列出本剧已有卡，不表示当前镜头没有引用。 最新视频任务失败但 video_asset_id 仍在时，标签为「已有视频，本次重生成失败」， 不得显示成没有视频。画布不是唯一播放入口。 行内提示来自连贯性检查、角色定妆状态与合规预检 （/previz/continuity-check、card_status、 POST /bgssai/user/compliance/precheck check_scope=SHOT： 命中片段高亮 + risk_category 中文 + 改写建议 + 「采纳改写」），仅在有问题时出现。 连贯性提示不阻塞生成（该镜生成按钮不禁用），可「忽略这条」——忽略留痕并计入分镜门 G2_STORYBOARD 评分；未定妆角色 / 场景 / 道具的镜头仍禁用生成（blocked_flag=1）。 顶部画面模型来自 GET /bgssai/user/ai-models/list?ability_type=IMAGE，未点选时默认 bgssai-image（BGSSAI Image）。VIDEO 模型来自 GET /bgssai/user/ai-models/list?ability_type=VIDEO，所选 model_code 为 bgssai-video，随单镜或批量任务提交；存在首帧时由服务端走图生视频，否则走文生视频。 页面与接口不展示网关编号。 首尾帧衔接：镜头 frame_link_mode（NONE / INHERIT_PREV / BOOKEND）经 POST /bgssai/user/shots/frame-link-save 与 /frame-link-batch 维护， 列表返回 last_frame_asset_id · last_frame_url · link_effective_flag · link_hint； 跨场次自动降级（downgrade_reason=CROSS_SCENE）；单独出尾帧走 POST /bgssai/user/shots/last-frame-generate（target_type=LAST_FRAME）； 模型是否支持首尾帧取 ai_model_config.config_json.support_last_frame，不支持却设 BOOKEND 返回 4006。 需求见 frame-continuity.md。 顶部展示剧本门（G1_SCRIPT）与预检状态徽标（中文）。 列表 GET /bgssai/user/shots/list?episode_id。 进阶能力（剧本工作台 / 图谱 / 质量门 / 走位等）全部收在侧栏「更多」， 需求见 docs/feature/storyboard-workbench.md 与 previz-text-storyboard.md。
