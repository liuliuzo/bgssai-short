# 易用性深查与本批修复（2026-11-16）

范围：用户端与管理端前端公共层、制作主链路、登录与订阅、两后端错误出口。只读审计正文后按影响排序。本批只落不改接口契约、字段、枚举、数据库的非功能修复；涉及新增可见控件或确认交互的条目留待原型确认。

## 本批已修复

| 条目 | 结果 |
| --- | --- |
| 分章表第二页按页内下标改章 | 按 `chapter_id` 在完整列表定位后改标题与合并 |
| 分镜批量估费与改编估费不失效 | 选择、任务类型、章节范围、集数、源任一变化即作废旧估费；确认改编与批量生成加在途禁用 |
| 任务中心翻到第二页被拉回第一页 | 筛选只置状态、统一回第一页；轮询只刷新当前页、仅有排队或执行中任务且页面可见时、静默不置加载态 |
| 支付已付误报超时与无限轮询 | 先查服务端状态再判超时；无时区到期时间按 Asia/Shanghai 解析；单飞轮询；无到期时间时本地 30 分钟封顶；超时与关单后刷新余额；扫码中遮罩与 Esc 不关窗 |
| 下单与新建作品连点重复提交 | 下单四个渠道按钮共用在途态；新建作品加提交中守卫与确认按钮加载态 |
| 会话失效重复清理与重复跳转 | 两端收敛单次守卫；被踢提示由登录页按 `reason=session_kicked` 呈现（管理端登录页补同口径）；同文提示合并为一条 |
| HTTP 错误丢弃服务端 message | 优先呈现响应体 `message`，无则用状态码既有文案；本地超时与连接失败分开提示 |
| 请求封装不透传配置 | 两端 `http` 方法增加可选 config 透传（timeout、signal、onUploadProgress），既有两参数调用不变 |
| 后端默认错误英文与空提示 | 两端 `CommonErrorCode` 默认 message 中文化（code 不变）；`IllegalArgumentException` 空消息回退参数错误文案且限长 240；管理端系统错误不回内部细节；限流 message 带可重试秒数；上传过大 message 带上限；参数类错误带字段与期望类型 |
