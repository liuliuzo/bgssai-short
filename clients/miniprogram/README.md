# bgssai-short WeChat miniprogram

One miniprogram with **two login entrances** (创作者 / 运营). Not a separate admin mini program and not a public-account H5 link substitute.

## Preview

1. Install WeChat DevTools.
2. Open `clients/miniprogram`.
3. Leave `appid` empty in `project.config.json` for tourist/test mode, or fill locally (do not commit secrets).
4. Adjust `userProductUrl` / `adminProductUrl` in `config.js`.

## Out of scope

- AppID secrets, business-domain whitelist, DNS, store submit
